# Кофейня в пяти эпохах — канон страницы

## Цель

Показать одну и ту же кофейню в пяти эпохах: 1200, 1800, 1980, сегодня (2026) и 2100. Сцена должна читать место как непрерывную историю, а не как пять несвязанных изображений.

## Состав

- `index.html` — единственный документ страницы; внешние библиотеки, видео и установка программ не используются.
- `images/1200.jpg`, `images/1800.jpg`, `images/1980.jpg`, `images/today.jpg`, `images/2100.jpg` — вертикальные JPEG. Каждый запрос указывает желаемый размер 768×1152; сервис может вернуть оптимизированный вариант с теми же пропорциями.
- Первый экран — контейнер пропорции 9:16; слайды укладываются друг на друга и сменяются с интервалом три секунды в цикле.
- Только CSS отвечает за плавное появление и медленный наезд (масштаб); JavaScript для смены слайдов не применяется.
- Внизу кадра крупная белая подпись года и названия эпохи. За пределами экрана повторяется статичная галерея с теми же пятью изображениями и подписями.
- После галереи размещается точная фраза: «Страницу собрал ИИ-агент за вечер по правилам Spec-Driven Company»; слова Spec-Driven Company являются ссылкой на исходный проект.

## Изображения

Каждый запрос идёт отдельно на `https://image.pollinations.ai/prompt/` с URL-кодированным английским описанием, параметрами `width=768`, `height=1152`, `nologo=true`, индивидуальным `seed` и `enhance=true`. Постоянные признаки: один фасад на углу каменной улицы, центральная дверь и большие передние окна, тёплый золотой час, фотореализм, вертикальный ракурс, отсутствие крупных планов людей.

Если сервис всё же добавляет служебную метку по нижнему краю JPEG, герой кадрирует её масштабированием изображения внутри контейнера; карточки галереи кадрируют нижний край через своё соотношение сторон. На странице метка не видна.

## Готово, когда

1. Локальная и опубликованная страница показывает все пять изображений без ошибок загрузки.
2. Герой-сцена имеет вертикальные пропорции 9:16, а подписи читаемы поверх каждого кадра.
3. Каждая эпоха занимает кадр в цикле примерно на три секунды; CSS-анимация выполняет плавный переход и наезд.
4. Под сценой видны пять подписанных карточек и требуемая строка со ссылкой.
5. Проект находится в публичном репозитории, GitHub Pages обслуживает ветку `main`, а публичный адрес `github.io` доступен.
